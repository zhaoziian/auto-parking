# Automatic Parking Simulation (Course Project)

This repository contains my course project for *Intelligent Control*.

The current implementation is **far from perfect** and has many limitations.  
I keep this repository mainly as a record of my learning process and technical exploration.

The project focuses on automatic parking (parallel parking and reverse parking) using:
- A kinematic bicycle model based on Ackermann steering
- A fuzzy controller for steering control
- Particle Swarm Optimization (PSO) for parameter tuning

At this stage, the algorithm performance is not ideal, and the parking accuracy is still limited.  
However, the purpose of this project is **not to present a polished solution**, but to document how my understanding of intelligent control, modeling, and optimization evolves over time.

I plan to continuously improve this repository by:
- Refining the vehicle and environment modeling
- Improving control strategies and objective functions
- Experimenting with alternative algorithms (e.g., MPC, sampling-based planning, learning-based methods)
- Updating code structure and simulation results

If any part of my learning process happens to be helpful or inspiring to you, I would be very glad.
